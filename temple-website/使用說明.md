# 尖山坑聖母宮｜互動求籤展示版

## 開啟
解壓縮整個資料夾後，雙擊 `index.html` 開啟原網站，點「開始求籤」。也可直接雙擊 `fortune.html`。請保留所有檔案在同一資料夾。無須安裝、連線或啟動伺服器。

這是依參考對話原始 HTML 修改的可執行版本，未修改任何既有線上網站。首頁保留原有介紹、沿革、神明介紹、公告、活動、相簿與聯絡區塊；這些資料仍是原先範例，正式上線前應由宮方確認。神像使用自製像素示意圖，並非本宮實際神像。五張參考圖僅用於操作流程，未移植其他宮廟的神像或籤詩。

## 體驗流程
靜心首頁 → 開始求籤 → 抽籤動畫 → 顯示籤號 → 擲筊動畫 → 筊象結果 → 查看完整籤詩與白話文。

- 引導展示：優先使用第 38 籤，固定聖筊；找不到 38 時使用資料第一筆。
- 隨機模擬：每筆籤等機率；筊象為聖筊 50%、笑筊 25%、陰筊 25%，僅程式展示設定，不聲稱是實物機率。
- 聖筊可閱讀籤詩；笑筊可回到同一籤號再次擲筊；陰筊可重新抽籤。任何階段皆可重新開始。
- 沒有收集姓名、生辰或所問事項；沒有網路請求、分析追蹤或雲端儲存。
- 具手機單欄版、鍵盤操作焦點、結果播報及減少動態效果支援。

目前全部籤詩均為明示佔位資料，沒有自行編造正式籤詩。即使匯入資料，擲筊仍是電腦模擬，不代表神明旨意；實際規則應依宮方指引。

## 匯入完整籤詩與白話文
1. 複製 `lots.example.json`，以 UTF-8 編輯。
2. 每首籤一個物件，依下面欄位填寫；poem 陣列的每一項為一行，可以不限四句。
3. 在求籤頁下方展開「籤詩資料管理」，選擇 JSON 檔案。
4. 頁面顯示已載入筆數後，從頭開始體驗。匯入失敗會保留原資料並顯示原因。

| 欄位 | 內容 |
| --- | --- |
| schemaVersion | 固定數字 1 |
| source | 資料來源，例如使用者提供、宮方確認的版本及日期 |
| lots | 所有籤資料的陣列 |
| number | 不重複的正整數籤號 |
| rank | 籤等文字；尚未確認請填「未提供」 |
| title | 籤題；若無請填「第 N 籤」 |
| poem | 完整詩文的字串陣列，每項一行 |
| explanation | 完整白話解釋；換行使用 JSON 的 \n |
| isExample | 範例填 true；確認是正式提供的資料才填 false |

匯入檔案限 2 MB、1–1000 筆；重複籤號、漏欄、空詩文會拒絕。匯入只存在目前頁面記憶體；重新整理恢復 `lots.js`。輸入文字以純文字顯示，不執行 HTML。

## 永久更新資料
開啟 `lots.js`，將 `window.TEMPLE_LOTS =` 後面的 JSON 物件替換成已驗證的完整內容，保留結尾分號。存檔後重新開啟網頁。無須修改流程程式。`lots.example.json` 是可下載格式範本，若希望下載內容同步，請一併更新。

## 檔案
- index.html：從先前對話還原並整合的原網站。
- fortune.html / fortune.css / fortune.js：求籤頁、樣式與流程。
- lots.js：預設資料。
- lots.example.json：匯入範本。
- deity.svg：神像像素示意插畫，可日後替換為宮方提供的圖片。
