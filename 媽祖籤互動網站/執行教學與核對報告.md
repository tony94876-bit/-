# 尖山坑聖母宮・媽祖籤互動網站

本機展示版本，未正式上線。像素神像為原創示意，並非宮方實際神像或已核准的視覺素材。

## 開啟方式

1. 將整包 ZIP 解壓縮，避免在壓縮檔內直接開啟。
2. 雙擊 `index.html`，選擇 Chrome、Edge、Firefox 或 Safari 開啟。
3. 按「進入殿堂」→「開始抽籤」→「擲筊・數位模擬」。聖筊後按「開啟籤詩」；笑筊、陰筊可重新抽籤。
4. 在籤詩卡片切換「籤詩原文／中文白話／English／日本語」。也可在下方輸入 1–100 直接查閱。

不需要安裝套件、不需要連網，也不需要建立帳號。資料、樣式、程式和像素神像全部包含在 `index.html`。請啟用瀏覽器 JavaScript。

手機檢視：可將 `index.html` 傳到手機並以支援執行本機 HTML 的瀏覽器開啟；部分手機的檔案預覽器不執行 JavaScript，此時需透過電腦本機伺服器或經確認後的網站網址開啟。頁面已設定手機單欄版型與可換行的文字內容，但本次未完成實機視覺驗證。

## 數位模擬規則

- 使用瀏覽器的隨機數功能，從 100 籤等機率抽取，透過拒絕取樣避免取餘數偏差。
- 每次模擬兩個獨立的面，各有 50% 機率為平面或凸面。
- 一平一凸為聖筊（50%）；兩平為笑筊（25%）；兩凸為陰筊（25%）。
- 示範流程以一個聖筊開啟籤詩；其餘兩種結果重新抽籤。
- 機率與流程僅屬程式設計，不聲稱等同真實筊杯機率或任何宮廟正式規範，不代表神明旨意。
- 不記錄個人問題，不傳送資料，不保存抽籤歷史。重新整理網頁即回到初始狀態。

## 檔案說明

- `index.html`：可單獨執行的完整網站，資料已內嵌。
- `籤詩資料.json`：100 籤及「頭籤」附錄、來源資訊與來源檔案 SHA-256。
- `核對報告.json`：可供程式讀取的筆數、缺號、重號及缺欄檢查結果。
- 原始 `.odt`：原封保留，方便宮方比對。
- 本文件：操作、來源、模擬規則與驗證範圍。

資料欄位：`number` 是數字編號；`source_number_and_poem` 保留原始第一欄（含編號與段落分隔）；`original` 僅移除前面的數字編號與分隔空白；`zh`、`en`、`ja` 是原三語解析；`source_row` 是表格列號（表頭算第 1 列）。ODT 段落以換行分隔，格式不轉成文字內容。

若日後修訂，請保留原始資料備份。網頁資料在 `index.html` 的 `fortune-data` 區塊內；單獨修改 JSON 檔不會自動改變網頁，必須同步更新內嵌資料，避免兩份版本不同。
